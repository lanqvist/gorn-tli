# Тюрьма Талоса (сезон 14): правила для своего симулятора

Спецификация правил мини-игры «Тюрьма Талоса» из Torchlight: Infinite, по
которой Горн строит свой движок. Записаны факты об игре: что видно на экране,
что сказано на картах орудий и что измерено по живым забегам. Чужой код
сюда не переносится.

Метки надёжности:

- **[факт]** видно в игре или написано на карте;
- **[замер]** измерено по живым забегам, с числом наблюдений;
- **[догадка]** толкование: проверить по своим кадрам и логам.

Где правило помечено догадкой, в движке оно настраивается параметром, а
не зашивается в код.

## 1. Поле

- Кольцо из 16 камер, номера 1–16 по часовой стрелке. Камера 1 —
  **допросная** (кабинет): в ней не бывает узников, она никогда не заперта.
  [факт]
- Соседи камеры — номера ±1 по кольцу. Расстояние — число шагов по часовой
  стрелке, `(b − a + 16) mod 16`. [факт]
- **Надзиратель** (золотая стрелка) стоит в одной камере. В начале забега он
  в допросной, все камеры 2–16 заперты. [факт]
- Камера бывает: заперта (замок, внутри неизвестный узник), открыта и
  пуста, открыта с узником. Над запертой камерой может стоять «!»
  (событие). [факт]

## 2. Узники

- Звери: **мамонт, лев, волк, крыса**. [факт]
- Редкости по возрастанию: Обычная (0), Магическая (1), Редкая (2),
  Легендарная (3), Величайшая (4), Призматическая (5, радуга). [факт]
- Призматический узник сразу уходит в **хранилище** (панель «Призматический
  узник» справа, 10 мест). Его камера снова запирается. Очки забега — число
  призматических в хранилище. [факт]
- Когда хранилище полно (10), рост останавливается на Величайшей. [факт со
  слов игрока]

## 3. День

Забег — 20 дней («Железный закон» — 30). Счётчик сверху: «До бунта осталось
N дн.». [факт]

1. **Утро.** Срабатывают утренние орудия (раздел 7), затем выпадают
   **пункты назначения** — карточки «Пойти в камеру N» под доской. [факт]
2. **Пункты назначения.**
   - Обычно 3. Каждое из орудий «Поддельный ключ», «Шипастая железная плеть»
     и «Столб для сожжения» убирает по одному, но меньше одного не бывает.
     [факт для Столба по карте, для остальных — догадка]
   - Утром без этих орудий в 16,9 % случаев карточек на одну меньше.
     [замер, 8 592 утра]
   - Карточки выбираются среди ближайших 6 шагов вперёд, допросная тоже
     считается; шаги 1–6 выпадают одинаково часто. [замер]
3. **Обход.** Игрок выбирает карточку, надзиратель идёт по часовой стрелке.
   Запертая камера назначения открывается, её событие срабатывает. Если
   назначение — допросная, начинается фаза допросной (раздел 5). [факт]
4. **Действие в камере надзирателя**, одно в день (ряд «Примите решение»):
   - **Пожирание** — узник надзирателя съедает другого (раздел 4);
   - **Замена** — узник надзирателя меняется на нового (раздел 6);
   - **Завершить день.**

   Пожирание и Замена в один день исключают друг друга. [факт] Игра
   показывает только доступные карточки: иногда нет Замены или нет
   Пожирания. [факт]
5. **Конец дня.** Когда дни кончились, забег окончен. [факт]

## 4. Пожирание

### Кто кого ест [факт для первой еды, замер для второй]

- **Первая еда:** мамонт → лев, лев → волк, волк → крыса, крыса → мамонт.
- **Вторая еда** — у узника от Легендарной редкости: мамонт ещё ест волка,
  лев — крысу.
- Есть можно узника **той же редкости**, что и едок. Есть узника ниже или
  выше нельзя, если орудие не разрешает. [факт]
- Призматический никого не ест. [факт]
- На экране цели едока показаны клыками. [факт]

### Укус

- Съеденный пропадает, его камера снова запирается. [факт]
- Едок получает +1 к редкости, сверху бонусы орудий (раздел 7). [факт]
- После укуса **зверь едока меняется случайно**, равновероятно среди
  четырёх, может остаться прежним. [замер: зверь сменился в 73 % из 141, это
  сходится с 3/4]
- **Цепочка.** Если у едока с новым зверем есть цели, игра предлагает
  «Выберите узника для пожирания» (затемнённая доска, цели в клыках). Игрок
  ест дальше или жмёт «Отменить». Цепочка продолжается, пока есть цели.
  [факт]
- Пожирание засчитывается для цели «Закон джунглей» за каждый укус.
  [догадка: за укус или за действие — проверить]

## 5. Допросная

Пришёл в допросную — выбор из двух карточек: [факт]

- **Наградить:** случайный узник ниже Призматической получает +1.
- **Подстрекнуть:** за 2 случайные запертые двери без события ставится
  событие из пула, «!» видно сразу.

## 8. События

Событие стоит за запертой дверью («!») или в открытой камере рядом с
узником. Обход в такую дверь запускает его; игрок принимает или
пропускает. [факт]

- **Шанс события за дверью в первый день — 6,4 %** [замер, 10 370 дверей].
  Позже — догадка.
- Какое событие выпадает: из пула, вероятно поровну. [догадка]

| Событие | Действие |
|---|---|
| Цепная реакция | следующий обход открывает все запертые камеры на пути, их события не срабатывают |
| Казнь | палач убирает свою первую еду ниже своей редкости; +1 за каждую жертву |
| За закрытыми дверями | узник становится Величайшим, зверь — из самых редких на поле |
| Ненасытный аппетит | случайный узник самой низкой редкости: 5 попыток +1 по 50 % |
| Опасный каторжник | случайная запертая камера открывается с Легендарным или Величайшим |
| Шёпот ворона | следующие 4 запертые камеры по часовой стрелке показывают редкость |
| Вкус свободы | открываются 3 случайные запертые камеры |
| Узурпация I–IV | рост узников, I → II → III → IV по цепочке; II ставится за случайную дверь |
| Крысиная тропа | «Выберите цель»: переход в любую камеру, кроме допросной, без шагов |
| «Охота за сокровищем» | запертые камеры с Обычным или Магическим показывают редкость, остальные — «не ниже Редкой» |

Кроме «Крысиной тропы» и «Шёпота ворона» в названиях и действиях есть
догадки. Сверить по своим кадрам событий.

окно «Сокровищница»: 4 подарка, взять 1. [факт] Из окна можно «Посмотреть
состояние тюрьмы» и вернуться. [факт]

| id | Название | Действие |

| ring | Трёхглавое кольцо | открывает до 3 случайных запертых камер |
| horn | Медный боевой рог | каждый узник, у которого есть цель, делает один укус (это не тратит действие дня) |
| wine | Багряное вино | все узники ниже Легендарной +1 |
| brand | Клеймо первородного греха | до 4 узников без еды меняют зверя так, чтобы еда появилась |

## 10. Цели и стартовые события

Цель видна на панели слева. Выполнил — выбор 1 орудия из 3. [факт]

| Цель | Условие |
|---|---|
| Загнанный зверь-царь | хотя бы 1 узник достиг Величайшей [факт] |
| Закон джунглей | всего 4 раза Пожирание [факт] |
| За дверью камеры | открыть 10 камер [факт] |
| Прогулка по тюрьме | пройти 18 клеток [догадка] |
| Подводные течения | 2 события [догадка] |

Стартовые события: Бой в клетке (едят на любой редкости, зверь после укуса

[догадка], кроме названий.

## 11. Чего не знаем и как узнать

Свои кадры с логом (папка «Горн — тюрьма») — главный источник: каждый
кадр лежит рядом со строками лога, которые его вызвали.

1. Шансы событий после первого дня и состав пула.
2. Порядок срабатывания орудий при открытии двери, утром и при замене.
3. Засчитывается ли «Закон джунглей» за укус или за действие.
4. Почему иногда открываются соседние двери без «Связки ключей» (157 случаев
   из 6 944).
5. Догадки из таблиц орудий и событий: прогнать свои кадры «до/после».
6. Шансы при замене в сравнении с дверью: живые замены чаще дают Редких
   (0,145 против 0,114).
7. Допущения движка (этап A). Где правило неясно, движок взял значение
   по умолчанию; число — в `Params` (`src/core/prison/model.ts`), порядок и
   толкования — в коде. Каждое проверить по своим кадрам:
   - **Обновление выбора** — одно на забег (`rerolls`), не на каждый выбор.
   - **Цели** — после выполнения выпадает другая случайная цель
     (`objectiveRepeat`). «Загнанный зверь-царь» при уже имеющемся
     Величайшем выполняется сразу. «Подводные течения» считают только
     принятые события.
   - **Действие дня** — после Пожирания (со всей цепочкой) или Замены день
     кончается сам: третьей карточкой остаётся только «Завершить день».
   - **Событие за дверью, которая снова заперлась** (съели, ушёл в
     хранилище) — 6,4 %, как в первый день (`relockEvent`). Событие двери,
     открытой не обходом, остаётся в камере и срабатывает при обходе в неё.
   - **«Тирания»** — за визит в допросную ещё 3 выбора «Наградить или
     Подстрекнуть» (`tyrannyExtra`), а не 3 раза оба сразу.
   - **«Изобилие»** — 3 подарка; сокровищница открывается после текущего
     действия, до следующего решения игрока (подарки за утро — до выбора
     двери, за укус — до решения о цепочке).
   - **Порядок при открытии двери обходом:** Жетон → Связка ключей →
     Поддельный ключ → Клеймо → Чёрный список (запертые считаются после
     открытия), затем Кандалы (по длине хода, при любом обходе, в том числе
     в открытую камеру и в допросную). «Крысиная тропа» открывает дверь
     и запускает её событие, но орудия обхода не срабатывают.
   - **Связка ключей** — 80 % по карте (`keysChance`), замер давал 63 %.
   - **Порядок утра:** гнёзда → Удушающая цепь → Монета → Щипцы → Когти →
     Ящик → Капкан → карточки.
   - **Шампур и Корона** — добавка к обычному +1: крыса итого +2, лев +3
     (`skewerBonus`, `crownBonus`). Может быть, у Короны «+2» — это итог.
   - **Молот** — формула и при той же редкости: прирост 2.
   - **Пила и Железная дева мстителя** — один раз после всего Пожирания
     (после цепочки), не после каждого укуса. Дева открывает случайную
     запертую камеру с первой едой едока его редкости.
   - **Ошейник** — «укус в цепочке» = любой укус после первого.
   - **Намордник** — в «узников осталось» входит и едок.
   - **Тесная клетка** — новый узник по шансам двери.
   - **Удушающая цепь** — при равенстве самых редких выбор случайный;
     убираются оба соседа, за каждого +1 с шансом 40 %.
   - **Монета** — пара и кто уходит выбираются случайно.
   - **Щипцы** — одна метка за раз, ставится утром, если меток нет; метка
     на камере, после замены в ней снимается. 4 узника — случайные,
     включая нового.
   - **Когти** — одна царапина за раз; сквозь дверь ест волк той же
     редкости, зверь за дверью любой; прирост 3 вместо 1, бонусы орудий
     сверху.
   - **Ящик** — одно гнездо за раз; дверь, открытая чем угодно до срока,
     уничтожает гнездо, узник обычный.
   - **Капкан** — добычу выбирает игрок, отказаться нельзя; охотник —
     самый редкий лев, который может её съесть; +1 обоим с ближайшего
     утра; охота пропадает, если кто-то из двоих ушёл или заменён.
   - **Замена:** Козёл отпущения заменяет бросок редкости (новый = прежний
     + 1), Столб смотрит на редкость прежнего узника и действует после
     Козла. Отсечённая дева при пустом поле (0 выше = 0 ниже) даёт +3.
     Весы закрепляют всех узников за дверями и показывают редкость и зверя
     лучшего.
   - **События:** Казнь убирает всех подходящих сразу; «За закрытыми
     дверями» — зверь, которого на поле меньше всех (сам узник не
     считается), при равенстве случайный; «Опасный каторжник» — 50/50
     Легендарный или Величайший; «Шёпот ворона» — от надзирателя по часовой;
     Узурпация — каждая ступень +1 узнику в камере события (`usurpGain`),
     следующая ступень за случайной запертой дверью без события; пул
     событий за дверью и от «Подстрекнуть» — 10 событий поровну, без
     Узурпации II–IV.
   - **Подарки:** Рог — камеры по порядку номеров, цель случайная, без
     цепочки; Клеймо не отбирает еду у уже накормленных им узников.
